# Python Libraries Lab: Colab notebooks

Beginner-friendly, **runnable** notebooks for essential Python libraries. Each notebook explains one library step by step with real code you run in Google Colab, then ends with a short exercise, an automatic answer check and a hidden solution.

**How to use:** click a badge below, then in Colab use **Runtime → Run all**, or press **Shift + Enter** on each cell. Nothing to install on your computer. To keep your changes, use **File → Save a copy in Drive**.
