# Python Libraries Lab: Colab notebooks

Beginner-friendly, **runnable** notebooks for 62 essential Python libraries. Each notebook explains one library step by step with real code you run in Google Colab, then ends with a short exercise, an automatic answer check and a hidden solution.

**How to use:** click a badge, then in Colab use **Runtime → Run all**, or press **Shift + Enter** on each cell. To keep your changes, use **File → Save a copy in Drive**.

**Runs column:** ✅ runs in Colab as-is · ⚙️ runs in Colab after its setup cell (for example, installing a database server or a browser) · 💻 the code is checked in Colab, and the app itself (a desktop window) runs on your laptop, with steps at the end of the notebook.

Many lessons share one practice dataset: orders from a made-up online store, *ShopEasy*. Each notebook creates the data it needs, so every notebook runs on its own.
